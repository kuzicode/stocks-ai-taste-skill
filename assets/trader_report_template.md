# 交易员速览模板（trader report）

skill 的 `report: trader` 输出模式使用本模板。设计原则：**结论先行、去术语、可直接挂单设止损**，30 秒读完。
过程内容（产业链定位、心智模型打分、估值推导）不进速览，留在完整 thesis YAML 存档里。

---

## 渲染规则（从 thesis YAML / _analysis 映射 → 速览字段）

| 速览字段 | 数据来源 | 口语化要求 |
|---|---|---|
| 一句话 | `core_thesis` | 去术语，点出核心矛盾（如「便宜是假象」「错杀是机会」） |
| 现价 | `price_outlook.current`（= HL `mark`）/ `hl_market` | 标「HL mark」；与现货背离则两个都写 |
| 🎯 长期（正股） | `decision.long_term`（call/仓位/加仓区） | buy→🟢/hold→🟡/watching→⚠️/sell→🔴 + 仓位 + 加仓区 + 持仓者动作 |
| ⚡ 短期（HL 杠杆） | `decision.short_term`（方向/杠杆/入场/止损/止盈/funding） | 方向 + **保守杠杆≤maxLev** + 入场/止损/止盈，附年化资金费成本 |
| 为什么（红/绿灯） | 取最关键 2-4 条 `supports` 或 `red_flags` | **每条带数字**，🔺=警示 / 🔹=利好 |
| 机构目标价 | `valuation.analyst_targets`（高/中/低） | 与自算公允价并列，注明家数/来源 |
| 关键日子 | 最近的 `catalysts_90d`（date+event+look_for） | 「盯 N 件事」列 2-3 个可观察点 |
| 价格剧本 | `price_outlook` base/bull/bear | 把 `(if ___)` 翻成「触发」列 |
| 跑路信号 | `red_flags[].trigger` | 直接用 trigger，改成口语祈使句 |
| 久期定性 | `chain_position.value_capture_tier` + `cross_check.moat_score` | 一句话：长持 vs 只 trade；强/弱护城河 |

emoji 信号约定（长期方向）：🟢 买入 ｜ 🟡 持有 ｜ ⚠️ 观望 ｜ 🔴 卖出/回避
**两角度可不一致**（长期 hold + 短期博财报小杠杆 long；或长期 buy + 短期因 funding 高观望）——各自给理由。
价格主源 = Hyperliquid `mark`（`scripts/hl_price.py`）；未上 HL 用现货并注明。

## 已填范例（MU，2026-06-15）

```markdown
# 📋 交易速览 · MU (Micron) — 2026-06-15

> **一句话**：便宜是假象。9 倍 PE 不是错杀，是周期顶部的"峰值盈利"。财报前别追。

**现价 $989**（HL mark）｜ 资金费年化 ~12% ｜ HL 最大杠杆 10x

## 🎯 长期 · 正股长期持有
**结论：⚠️ 观望 / 不追高** ｜ 建议仓位 **0–3%**（弱护城河+周期顶，不当核心长持）
加仓区 **$650–800**（按正常化毛利估，当前价不在安全边际内）｜ 持仓者 → 减磅 + 收紧止损。

## ⚡ 短期 · Hyperliquid 合约杠杆
**方向：⚠️ 观望（财报前不开仓）** ｜ 若博财报：杠杆 **2–3x**（≤10，严控）
入场 **$960–990** ｜ 止损 **$900**（破位即砍）｜ 止盈 **$1100–1300** ｜ 资金费年化 ~12%（做多要扣）
理由：6/24 财报是二元赌，仓位顶部、波动大 → 只小杠杆赌方向，不与长期混仓。

## 为什么（3 个红灯）
- 🔺 **涨太狠**：一年涨了 +746%
- 🔺 **毛利反常高**：指引 81%，历史常态只有 35–45% → 大概率回落
- 🔺 **低 PE 是陷阱**：9 倍 = 高盈利 ÷ 便宜倍数，典型周期顶（不是越低越好）

## 🏦 机构目标价（12 个月，约 30 家 · 示例占位，实跑须 WebSearch）
低 **$700** ｜ 中位 **$1050** ｜ 高 **$1400**　vs 自算公允价 $700–1100（机构追涨、自算按正常化毛利更保守）

## 📅 关键日子：6/24 财报 — 只盯 3 件事
1. 毛利还能不能守住 ~81%
2. 2027 年 HBM 合约价是涨还是跌
3. 营收有没有冲到分析师上限 ~$40B

## 价格剧本（未来 90 天）
| 情景 | 区间 | 触发 |
|---|---|---|
| 基准 | $850–1050 | 财报符合预期 |
| 🟢 利好冲 | $1100–1300 | 营收近 $40B + 2027 合约价坚挺 + 毛利保 80%+ |
| 🔴 利空砸 | $650–800 | 毛利见顶回落 / DRAM 现货价转弱 |

## 🚨 认错跑路信号（出现就走）
- 下季毛利指引环比下调，或 DRAM/NAND 现货价连跌
- SK 海力士 / 三星扩产压价
- 出货增速 > 涨价增速（供过于求先兆）

## 一句话定性
弱护城河 + 周期顶部 → 这是 trade，不是长持。对照 NVDA（强护城河+错杀=机会），MU 同样低 PE 却是陷阱。

> ⚠️ 仅为分析框架演示，非投资建议；数字以一手财报为准。
```
